# My Text Analyzer Project

## What is does ?

A basic text/string analyzer I created which asks the user to enter some text and then gives several statistics related to it.

## Features

The program can:

- Count the total number of characters
- Count characters excluding spaces
- Count the number of words
- Count vowels
- Count consonants
- Count digits
- Count uppercase letters
- Count lowercase letters
- Display the first word
- Display the last word
- Check whether the word "Python" appears
- Reverse the text character by character
- Search for a specific character
- Search for a specific word

  
## How to Run

Make sure Python 3 is installed.

Open a terminal in the project folder and run:

python3 text_analyzer.py

Then enter some text when prompted.
